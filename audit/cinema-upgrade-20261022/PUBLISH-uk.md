# Публікація результатів аудиту

Після завершення аудиту власник дозволив push. Пакет призначений для гілки `audit/torrents-cinema-20261022` у gorlim590/lampa, на основі main `51191957278e08ca6ed3631b310aa6fd6740c121`. Main і встановлена публічна версія плагіна не змінюються автоматично.

Код, документація, тести, JSON-докази та скриншоти включені. Приватні налаштування, cookies, storageState, токени й резервні копії користувацьких даних виключені. Єдина копія у backups — публічний початковий JS для автономного запуску offline-тестів.

У клоні репозиторію виконайте `git fetch origin`, потім `git switch --track origin/audit/torrents-cinema-20261022`. Локальні тести: `node audit/cinema-upgrade-20261022/offline.cjs` та `node audit/cinema-upgrade-20261022/state-tests.cjs`.

Для браузерних тестів потрібні встановлений Playwright і чинна тестова вкладка на CDP 9222. Частина спеціальних сценаріїв використовує приватні локальні копії/попередню конфігурацію й не є автономною після клонування; вони не публікуються. Режим upgraded підміняє відповідь JS плагіна лише в активній вкладці. Не запускайте новий браузер і не очищайте сховище.

Локальні коміти до публікації наведено у COMMITS.txt; GitHub-коміт пакета має власний хеш, оскільки пакет побудовано на справжньому main, а не на ізольованій історії доставки.
