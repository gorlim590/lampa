# Stremio × Lampa

Готовий плагін: `ui/stremio-hybrid.js`. Робоча Git-гілка `design/stremio-hybrid-x11` у `audit/stremio-hybrid-20261022/repository`. У корені workspace Git-репозиторію немає. Файл теми продубльований у кореневій `ui/` для локального попереднього перегляду.

## Що зроблено

Темна палітра Stremio, компактна бічна панель з розгортанням штатним контролером, просторі ряди Home, шість колонок Discover, світла рамка фокусу, scale 1.035 за 160 мс. Наявні картки YDesign, Interface+, Cardify+, рейтинги, жанри, UA, Trakt-статуси та рекомендації залишаються у своїх компонентах. Немає власних запитів, кешу, таймерів, observer чи обробників на картках. Тема прибирає blur бейджів і декоративний блиск YDesign та враховує reduced-motion. Lazy rendering і мережеві обмеження наявних плагінів не змінювалися.

Discover відкривається штатно: бічне меню → Фільтр → критерії → Розпочати пошук. Жанри, тип, рейтинг, рік та сортування залишаються механізмами Lampa. Верхні три dropdown та правий preview Stremio не реалізовано: використовуються наявні панелі Lampa, з новою палітрою і сіткою. Деталі перевірено на відкриття/повернення; повного редизайну деталей P2 немає.

## Запуск і вимкнення

У поточній вкладці тема вже ввімкнена. Після перезавантаження сторінки для повторного локального перегляду:

```bash
cd /home/gostrimchik/lampa-testing
node audit/preview-hybrid.cjs
```

Скрипт використовує лише наявний Chromium/CDP, не закриває браузер і не очищує дані. Плагін не додано до постійного списку завантаження: URL у GitHub Pages поки не існує, push/merge не виконувалися. Для постійного встановлення після окремо дозволеної публікації потрібно розмістити `ui/stremio-hybrid.js` та завантажувати його після Interface+/YDesign/Cardify+. Публікація не є частиною цієї локальної доставки.

Перемикач: Налаштування → Інтерфейс → Stremio × Lampa. Вимкнення видаляє CSS і клас теми, повертаючи попередній дизайн. Консольний API: `StremioHybrid.setEnabled(false)` / `true`; `StremioHybrid.destroy()` повністю знімає тему й pending appready handler. Після destroy файл можна завантажити повторно; налаштування реєструється один раз на сторінку. Єдиний власний ключ — `stremio_hybrid_enabled`; авторизації та дані інших плагінів не змінюються.

## Перевірки та порівняння

`audit/hybrid-results/report.json`: Home 720p/1080p/4K, Right/Down, OK/Back, незмінність вузлів і метаданих при п'яти перемиканнях — PASS. `p1-report.json`: Discover у трьох роздільностях, реальне меню жанрів, вертикальний скролінг, розгортання меню, reduced-motion — PASS. `final-report.json`: чисте завантаження, один перемикач, увімкнення/вимкнення, 23 рейтинги/38 жанрів/10 UA до й після — PASS. `lifecycle-report.json`: destroy/reinit та горизонтальний скролінг — PASS.

Під час чистого завантаження перевірка знайшла неправильне використання callback перемикача; виправлено читанням штатного Storage. Тести повторено успішно. YDesign завантажується асинхронно: перед перевіркою метаданих треба дочекатися `.activity--active .ydesign-rating`, а не лише appready.

Сім екранів справжнього Stremio — `stremio-reference/`. Home і Discover порівняно з Lampa у 1717×1050: `comparison-home-1717.png`, `comparison-discover-1717.png`; Stremio має віконну рамку ОС, тому порівняння композиційне, а не pixel-perfect. Найбільші розбіжності виправлено: приховане меню, надмірна ширина карток і переповнення контенту. Збережено шість більших збагачених карток замість восьми чистих постерів Stremio; висота рядів більша через рейтинги та бейджі. Фінальний Home — `home-final.png`.

BLOCKED: фізичний Google TV Streamer, реальний пульт, GPU/пам'ять та тривале користування. Емуляція 4K підтверджує лише верстку. З'являлося штатне повідомлення про незавантажений сторонній `wtch.ch/m`; цей плагін не змінювали. Онлайн-провайдери, відтворення, зміни Trakt на сервері та повна матриця горизонтальних/мобільних карток не перевірялися.
