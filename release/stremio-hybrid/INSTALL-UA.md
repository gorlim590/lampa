# Stremio × Lampa 1.1.0

Продовження гілки `design/stremio-hybrid-x11`, без перезапуску проєкту. Git-репозиторій: `audit/stremio-hybrid-20261022/repository`. Основний файл — `ui/stremio-hybrid.js`; копія в кореневій `ui/` використовується локальним сервером. Поточне desktop-приймання чистого запуску пройдено: штатні reload із вимкненою/увімкненою темою та відкритими налаштуваннями завантажують Home й метадані без ін’єкцій. Це кандидат для Google TV; фізичний пристрій і довга сесія ще не перевірені. Попереднє зависання не відтворилося, його історичну причину не доведено. Публікація потребує окремого дозволу.

## Дизайн та сумісність

Home: темна палітра, компактна бічна навігація з розгортанням штатним контролером, шість збагачених карток у ряду. Discover: штатний «Фільтр» → критерії → «Розпочати пошук», шість колонок, нове оформлення меню. Збережено компоненти YDesign, Interface+, Cardify+, Trakt+, постери, рейтинги IMDb/TMDB, жанри, UA, статуси/затемнення переглянутого та кастомні ряди.

Деталі фільмів/серіалів: повна назва, контрастний опис, темний фон, узгоджені кнопки; збережено прогрес серій, жанри, рейтинги та всі дії провайдерів/Trakt. Налаштування отримали спільну палітру, типографіку та фокус. Порівняно з фактичним Stremio через X11: перенесено контраст, заокруглення й ієрархію, збережено композицію Cardify та функціональні панелі Lampa. Правий список потоків Stremio та його три верхні dropdown не дублюються.

Тема не додає запитів, таймерів, observer або обробників на картках. Є один тимчасовий app/ready listener до готовності Lampa; він видаляється після ініціалізації або destroy. Після старту тема додає один style та один параметр у штатний реєстр налаштувань. Метадані не переписуються. Фокус 1.035/160ms, переважно transform/opacity; без додаткового blur, без stagger кнопок. Reduced-motion підтримується. Lazy rendering, кеш та обмеження запитів наявних плагінів залишаються їхньою відповідальністю.

## Що вже встановлено на цьому ПК

У штатні «Розширення» Lampa додано тільки один новий URL:

```text
http://127.0.0.1:8766/stremio-hybrid.js
```

Перезавантаження Lampa завантажує тему через цей URL **без CDP-ін'єкції**. Локальний сервер слухає виключно loopback і віддає тільки файл теми; інші плагіни та їхні адреси не змінено. Тема зараз увімкнена. Якщо сервер зупинено або ПК перезапущено, запустити його знову:

```bash
cd /home/gostrimchik/lampa-testing
node audit/serve-hybrid.cjs
```

Це сервер локального preview, без автозапуску ОС та без доступу з Google TV. Старий `audit/preview-hybrid.cjs` лишається допоміжним інструментом; для звичайного reload він більше не потрібен. Постійний сервер публікації не налаштовано; push/merge не виконувалися.

## Увімкнення, вимкнення, видалення

Налаштування → Інтерфейс → Stremio × Lampa. Вимкнення видаляє CSS і клас теми, повертаючи попередній дизайн. Єдиний власний ключ — `stremio_hybrid_enabled`; його стан зберігається між завантаженнями.

Для повного видалення: вимкнути тему, у «Розширеннях» видалити лише вказаний localhost URL і перезавантажити Lampa. Інші плагіни залишити. Локальний сервер можна завершити. Консольний API: `StremioHybrid.setEnabled(false)` / `true`, `StremioHybrid.refresh()`, `StremioHybrid.destroy()`. Після destroy можливе повторне підключення файла без дублювання налаштування. Destroy не стирає збережений вибір користувача.

## Встановлення на Google TV після дозволеної публікації

1. Взяти перевірений файл із `release/stremio-hybrid/`. Його checksum — у `SHA256SUMS`.
2. Після окремого дозволу розмістити файл на доступному для TV HTTPS-хості. URL має віддавати JavaScript із HTTP 200. Поточний файл ще не опубліковано.
3. У Google TV Lampa → Налаштування → Розширення → Додати плагін: ввести фактичний HTTPS URL. `127.0.0.1` із ПК для телевізора не підходить.
4. Завантажувати після Interface+/YDesign/Cardify+, зберігши їхні поточні налаштування. Не додавати тему водночас у loader і Розширення: одного способу достатньо. Захист від дублювання є, але дублювати мережеве завантаження не потрібно.
5. Перезавантажити Lampa. Увімкнути тему в Інтерфейсі. Перевірити Home/Discover, довгі назви, жанри/UA/рейтинги, переглянуте, деталі/серії, стрілки, OK/Back і кількахвилинне прокручування.
6. Вимкнути й увімкнути тему, перевірити збереження вибору після reload. Якщо плавність або читабельність недостатні, вимкнути тему й зафіксувати модель пристрою/роздільність для наступного профілювання.

## Фактично виконані перевірки

Актуальні перевірки запуску — `audit/hybrid-v3/`. Візуальні/регресійні артефакти `audit/hybrid-v2/` та попередні `audit/hybrid-results/` збережені.

- `lifecycle-unit.cjs`: PASS до appready без jQuery, скасування pending ready, 10 destroy/reinit, один параметр, false/0 та settings callback.
- `stability.json`: PASS 20 циклів у справжньому Chromium, один style/параметр, app listeners 32→32 та activity listeners 12→12. Script tags тесту не є DOM-накладними витратами теми.
- `details-report.json`: PASS 12 перевірок — фільм/серіал у 720p/1080p/4K, назва/опис не перекриваються, кнопка фокусу повністю видима, action focus, Back, налаштування.
- `regression.json`: PASS 16 перевірок — Home/Discover у трьох роздільностях, стрілки, навігація, reduced-motion, сумісність активних UI-плагінів, незмінність вузлів/метаданих, зелені галочки та затемнення.
- 30 перемикань: DOM counters після GC — 7246→7246, JS event listeners 2601→2601. JS heap 59,998,856→60,006,668 байт (+7812); це короткий вимір Chromium із роботою інших плагінів, а не гарантія відсутності довготривалих витоків.
- `native-load.json`: PASS завантаження через штатне Розширення після reload, HTTP 200, без ін'єкцій, один стиль/параметр. `audit/hybrid-v2/reload-report.json` зберігає історичний BLOCKED; актуальні результати — у `audit/hybrid-v3/native-reload.json` і `settings-reload.json`: 7 PASS без ін’єкцій, включно з даними Home та enabled/disabled.
- Нові pageerror у завершеній матриці деталей і регресії: 0. Перевірки після resize чекають штатний перерахунок Lampa; appready без готової Activity недостатньо для навігації тестом.

BLOCKED: фізичний Google TV, реальний пульт, апаратні FPS/GPU/пам'ять і довга сесія. Відтворення та зміни серверних списків Trakt не виконувалися. Горизонтальні/мобільні картки не мають повної регресійної матриці. Відоме стороннє повідомлення про `wtch.ch/m` не виправлялося. Історія попереднього сеансу: після серії reload Home залишився порожнім у native activity--load; clean Home URL та нова навігація не дали карток у відведений час. CSS вимкнено для контрольної перевірки — loading залишився. На продовженні Home відновився при звичайній навігації, а 7 нових перевірок приймання пройшли без змін коду теми. Історичну причину не встановлено; не списувати її автоматично на мережу чи чужий плагін. Артефакти: home-reload-blocker.json, reload-report.json і final-state.png. Lampa.Listener.send перевірено: він копіює список перед dispatch, тому видалення pending app listener не пропускає сусідні callbacks.

Наступні кроки: фізичне TV-профілювання, спостереження за повторенням історичного Home loading з фіксацією знеособлених помилок/часу запитів й перевірка читабельності, потім окремо дозволена публікація та підтвердження завантаження на самому TV. ## Остання контрольна точка після resume

Гілка design/stremio-hybrid-x11, попередній коміт паузи 77a1d0d. Код 1.1.0 не змінювався.

`audit/hybrid-v3/diagnose.json`: Home 28 карток, loading=false, немає нових JS errors або незавершених запитів після спостереження. Збережено лише origins/статуси, без URL-параметрів, headers і тіл відповідей.

`native-reload.json`: PASS disabled reload (~11.0s), enabled reload (~10.5s), 22 рейтинги після native запуску. На кожному старті один параметр; style 0/1 відповідає вибору. У тесті немає addScriptTag, startup-script, перехоплення/підміни відповідей або очищення сховища.

`settings-reload.json`: PASS reload із відкритим Інтерфейсом (28 карток), фокус Right після повернення до контенту, один extension/style/параметр. Наявна стороння помилка сертифіката wtch.ch не завадила цим перевіркам; TLS/налаштування стороннього плагіна не змінювалися.

Висновок: актуальний критерій native clean-load PASS. Попередня причина зависання залишається недоведеною; ці результати не є заявою, що виправлено невідомий баг ядра або підтверджено довгу роботу Google TV.
