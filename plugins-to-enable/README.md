# Плагіни для окремої активації

Ці файли не підключаються через `loader.js` автоматично.

## home-history.js — Issue #25

Два незалежні рядки Home: «Продовжити перегляд» із підтверджених локальних позицій та «Переглянуто» через Trakt+. Потрібні штатні Timeline/Favorite/ContentRows; для рядка «Переглянуто» також Trakt+.

Після merge і публікації GitHub Pages додайте в Lampa → Налаштування → Розширення URL:

```
https://gorlim590.github.io/lampa/plugins-to-enable/home-history.js
```

До публікації цей URL не є підтверджено доступним. Draft PR не активує плагін у вашій Lampa. Підключайте один раз; рекомендовано після основного loader. Модуль підтримує обидва порядки з YDesign через мінімальний guard, не копіюючи watched-логіку PR #29.

Для вимкнення вимкніть цей запис розширення та перезавантажте Lampa. Історія, Timeline і користувацькі налаштування не видаляються.

## Керування Home — Issue #30

Той самий `home-history.js` автоматично підвантажує сусідній `home-policy.js`; окремо його не активуйте. Після публікації обидва файли мають бути доступні за одним базовим шляхом.

У **Налаштування → Головна сторінка → Порядок рядків Home** виберіть рядок, перемістіть вище/нижче або на конкретну позицію. Підтверджені зміни зберігаються автоматично для поточного профілю; є скидання порядку. Невідомі сторонні рядки без стабільного ID залишаються на місці.

Приховуються лише перевірені рекомендаційні функції ядра на Home. Trakt та сторонні плагіни залишаються; пошук/каталог не змінюються. Докладно: [залежності, перевірки та обмеження](../docs/issue-30-home-order.md).
