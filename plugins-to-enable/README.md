# Плагіни для окремої активації

Більшість файлів у цьому каталозі не підключаються через `loader.js` автоматично. Вбудовані винятки перелічені в `loader.js`.

## home-history.js — Issue #25

Два рядки Home: «Продовжити перегляд» із підтверджених локальних позицій та «Переглянуто» через Trakt+. Для них потрібні штатні Timeline/Favorite/ContentRows та Trakt+.

У поточній конфігурації це **вбудований модуль**: `loader.js` автоматично завантажує Trakt core → Trakt+ → Home Policy → Home History. На старті стара Home прихована; вона з'являється після побудови Trakt-категорій. Додавати URL у «Розширення» не потрібно. Не реєструйте той самий файл вручну, інакше можливе подвійне завантаження.

Це правило набуде чинності у вебверсії лише після публікації відповідного `loader.js` і залежних файлів на сайті. Сам Draft PR не змінює активний сайт.

## Керування Home — Issue #30

`loader.js` завантажує `home-policy.js` перед `home-history.js`; обидва файли мають бути опубліковані за одним базовим шляхом.

У **Налаштування → Головна сторінка → Порядок рядків Home** виберіть рядок, перемістіть вище/нижче або на конкретну позицію. Підтверджені зміни зберігаються автоматично для поточного профілю; є скидання порядку. Невідомі сторонні рядки без стабільного ID залишаються на місці.

Приховуються лише перевірені рекомендаційні функції ядра на Home. Trakt та сторонні плагіни залишаються; пошук/каталог не змінюються. Докладно: [залежності, перевірки та обмеження](../docs/issue-30-home-order.md).
