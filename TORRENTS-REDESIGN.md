# Torrents Cinema — Lampa / Google TV

Один файл: [`torrents-redesign.js`](https://gorlim590.github.io/lampa/torrents-redesign.js). Налаштування → Розширення → Додати плагін → вставити URL → перезавантажити Lampa. Попередні додані оформлення торентів із Interface+ прибрано; новий файл не входить до loader, тому дублювати його не потрібно.

Налаштування → «Торенти · Кіно»: увімкнення; «Кіно (адаптивний акцент)» або «Мінімум (фіксований синій)». Мінімум не аналізує зображення та вимикає розмиття панелі. При видаленні цього одного URL й перезавантаженні повертається нативна сторінка з рештою ваших плагінів. `window.TorrentsRedesign.destroy()` прибирає декоратор із поточної вкладки без перезавантаження.

Пульт: ↑/↓ — рядки або елементи поточної групи; ← зі списку — ліві кнопки, → з лівих кнопок — рекомендований реліз; ↑ із першого рядка — фільтри; OK — чинна дія Lampa, Back — попередній екран. Довге OK залишає штатне меню рядка. Вкладки якості застосовують штатний фільтр до всього набору результатів, а не лише приховують видимі рядки. Сортування, фільтри, пошук і джерела відкривають штатні обробники. «Найкращий вибір» — евристика серед завантажених у поточному списку релізів, а не перевірка працездатності торента. Відтворення починається лише після натискання користувача.

Фон — TMDB w1280, запасний варіант — розмитий постер. Акцент рахується один раз на зображення з canvas 32×18; CORS/помилка дає резервний червоний колір. Кеш обмежений 64 записами. Один MutationObserver лише на контейнер списку; доступні якості читаються зі штатного Parser.get callback, без дублювання запиту. Колекція фокуса перебудовується при рендері, а не на кожну стрілку. Без постійних таймерів і сторонніх бібліотек. Шрифти: встановлені Unbounded/Manrope, далі system-ui/sans-serif; зовнішні шрифтові запити не потрібні, офлайн працюють резервні шрифти.

## Селектори, підтверджені в живій збірці

| Елемент | Селектор |
| --- | --- |
| Корінь / фільтри | `.explorer`, `.explorer__files-head .torrent-filter` |
| Ліва панель / постер | `.explorer__left .explorer-card`, `.explorer-card__head-img img` |
| Назва / жанри / опис | `.explorer-card__title`, `.explorer-card__genres`, `.explorer-card__descr` |
| Список / рядок | `.explorer__files-body .scroll__body.torrent-list`, `.torrent-item.selector` |
| Назва релізу / якість / аудіо | `.torrent-item__title`, `.torrent-item__ffprobe .m-resolution`, `.torrent-item__ffprobe .m-audio` |
| Сіди / піри / бітрейт | `.torrent-item__seeds span`, `.torrent-item__grabs span`, `.torrent-item__bitrate span` |
| Дата / розмір / трекер | `.torrent-item__date`, `.torrent-item__size`, `.torrent-item__tracker` |
| Штатні дії | `.filter--sort`, `.filter--filter`, `.filter--parser`, `.filter--search` |
| Фокус пульта | `.selector.focus` |

Декоратор зберігає оригінальні вузли та їхні OK/довгі OK обробники. Дані отримує з події `torrent:render`, метадані фільму — з активної activity; при відсутності вихідних даних читає наведені DOM-вузли. Невідомі аудіодоріжки й кодеки не вигадуються; UA означає заявлену в назві доріжку, а не результат ffprobe. Для пульта використовується окрема колекція Lampa.Controller та прокрутка наявного контейнера; старе трансформування списку на hover:focus перехоплюється тільки для оформлених рядків.

Публічний макет Claude під час роботи повернув оболонку, а його дані — 404; реалізація спирається на надану текстову специфікацію. Браузерна перевірка роздільностей не є вимірюванням FPS на фізичному Google TV Streamer 4K.
