# Торенти · Кіно 1.2.0-audit

Локальна версія для перегляду й тестування в Lampa на Google TV. Основний файл — `torrents-redesign.js`, зі своїми стилями, без нових бібліотек і зовнішніх шрифтів. Публічний GitHub не змінено.

## Поведінка

Рядки зберігають справжні назви парсерів, рік із метаданих, якість, розмір та постійно видимий трекер. Назва переноситься, кількість рядків налаштовується, у фокусі доступна розгорнута назва. Штатні вузли Lampa, OK, довге OK, сортування, фільтри, пагінація, TorrServer і плейлисти збережені.

Кнопка **«У Watchlist Trakt»** працює саме з Watchlist Trakt за останнім побажанням власника. Використовується вже підключений `TraktTV.api`: читання стану, додавання/видалення, повторна перевірка збереження. Фільми і серіали мають окремі типи. Кнопка одразу показує очікуваний стан і «збереження…», повторний запит під час збереження блокується. Помилки й непідтверджений стан відображаються явно. Ця кнопка не змінює локальне/CUB-обране, історію, оцінки або колекцію Trakt. Без інтеграції Trakt показується відповідне повідомлення.

Трейлери використовують відео поточної картки, альтернативні Trailer/Teaser, український запит і резервний англійський запит. Повтори прибираються, порожній результат повідомляється. Збережені штатний плеєр Lampa та налаштування запуску YouTube на Android. Back повертає фокус у торентну сторінку. Доступність самого відео залежить від YouTube.

## Найкращий вибір

Спочатку перевіряються назва, доступний рік фільму, сезон та епізод із контексту/штатного фільтра. Інший рік, інший сезон, невідповідна серія та колекція замість окремого фільму виключаються з рекомендації. Такі рядки залишаються доступними для ручного перегляду з поясненням.

Серед допустимих рядків пріоритети: українське аудіо → українські субтитри → інші релізи. Усередині цих груп враховуються сіди, бітрейт, бажана роздільна здатність, розмір та встановлений порядок джерел. Український трекер сам по собі не є доказом українського аудіо. Підтримуються назви доріжок, явні мовні поля і стандартні потоки ffprobe. Порядок джерел є налаштуванням користувача, а не перевіреною оцінкою надійності трекера.

Рекомендація обирається серед уже відображених штатною пагінацією рядків поточного фільтра. Вона не перевіряє фактичну доступність піра, не запускає відео автоматично і не є гарантією правильності кожного незвичного релізу. За невідомого сезону відображається попередження. Точне зіставлення альтернативних назв залежить від метаданих.

## IMDb на сторінці файлів

За замовчуванням оцінки завантажуються **лише для рядків, які зараз перетинаються з видимою областю**, включно з частково видимим рядком. Запасу завантаження поза екраном немає. Нові рядки отримують оцінки при прокручуванні. Перед запуском запиту з черги видимість перевіряється повторно. Отримані оцінки зберігаються в обмеженому кеші поточної сесії; повторний показ не дублює запит. Уже розпочатий запит може завершитися після прокручування, і його результат потрапить у кеш.

Для серій використовуються сезон і номер із Lampa, підтверджені епізодами сезону TMDB. Далі окремий IMDb ID епізоду отримується через TMDB external_ids. Відповідь OMDb перевіряється за типом `episode`, IMDb ID епізоду, IMDb ID серіалу, сезоном і номером. Оцінка всього серіалу не підставляється. Сезон 0 підтримується; неоднозначна подвійна/абсолютна нумерація показує порожній стан.

Для фільму перевіряються тип `movie` та точний IMDb ID. У багатофільмових списках інші фільми й sample не отримують оцінку батьківської картки. Невідомі/непідтверджені дані показуються як `IMDb —` із поясненням.

Використовується вже налаштований `omdb_api_key`; ключ не додається в код і не змінюється. Позитивні дані кешуються на 24 години в межах поточної JS-сесії, негативна відповідь — на 15 хвилин. Загальний кеш обмежений 64 записами. Плагін має власний денний ліміт OMDb 20/50/100, стандартно 50; інші плагіни можуть витрачати спільну квоту ключа. [OMDb вказує 1000 запитів/день для безкоштовного плану](https://www.omdbapi.com/apikey.aspx); план поточного ключа не визначався.

## Кольори та продуктивність

Пріоритет — логотипи uk/en/без мови, до чотирьох кандидатів, потім постер і backdrop. Аналізуються непрозорі насичені пікселі canvas 64×36; білий/чорний/сірий фон ігнорується. Під час очікування логотипу аналіз постера не запускається. CORS або помилка дає безпечний резервний колір. Є ручний `#RRGGBB`, який працює також у мінімальній темі. Колір тексту активних елементів обирається за яскравістю акценту.

Стандартна оптимізація Google TV вимикає backdrop blur, blur постера та масштабування рядків. Анімації стандартно вимкнені. Кеш метаданих/кольорів має TTL 6 годин і обмеження розміру; невдалі кольори кешуються коротше. Запити метаданих об'єднуються й обмежуються 1/2/4 паралельними, стандартно 2; таймаут 8 секунд. Ці обмеження не змінюють глобальні запити інших плагінів або самої Lampa. Спостерігачі, таймери та запити прибираються при закритті файлів/знищенні activity, застарілі activity звільняються.

## Налаштування

- **Оформлення:** джерело акценту, ручний колір, інтенсивність сяйва, непрозорість панелі Google TV, затемнення, компактні/розширені картки, рядки назви, рейтинги картки, IMDb файлів, анімації. Трекер завжди видимий.
- **Торенти:** пріоритет українських доріжок, аудіо й субтитрів, бажана роздільна здатність, рекомендація, фільтр Толоки/Мазепи, приховування дублів за підтвердженим infohash, пояснення підозрілих збігів.
- **Продуктивність:** Google TV, кеш метаданих/кольорів, паралельні запити, завантаження IMDb тільки у видимій області, денний бюджет OMDb.

Власні параметри читаються зі збереженням `false`, `0` і рядкових значень роздільності: у цій збірці `Storage.get` може замінювати хибні значення значенням за замовчуванням.

## Керування

↑/↓ — рядки поточної групи; ← зі списку — кнопки зліва; → з кнопок — список; ↑ із верхніх елементів — штатний хедер; OK — дія; довге OK — штатні дії; Back — закриття меню/файлів/плеєра або попередня сторінка. Для ручного кольору використовується стандартна клавіатура Lampa.

## Перевірки і застосування

Детальний звіт: `audit/cinema-upgrade-20261022/RESULTS-uk.md`. JSON, скриншоти 1080p/4K і сценарій фізичного TV лежать поруч. Браузерні перевірки використовують тільки активну вкладку через CDP, без нових браузерів/профілів/контекстів.

Локальні тести:

```sh
node --check torrents-redesign.js
node audit/cinema-upgrade-20261022/offline.cjs
node audit/cinema-upgrade-20261022/state-tests.cjs
```

Перегляд у наявній тестовій сесії:

```sh
node audit/active-session.cjs cinema-audit upgraded
```

Сценарій тимчасово підміняє відповідь на JS плагіна в цій вкладці та прибирає маршрут після тесту. Загальне перезавантаження знову завантажить публічну версію, поки оновлений JS не розміщено за встановленою адресою.

Для застосування в окремому актуальному клоні `gorlim590/lampa` використайте підготовлений patch лише для `torrents-redesign.js` або скопіюйте цей файл. Цю інструкцію можна перенести до `TORRENTS-REDESIGN.md`. Публікація, push і merge під час аудиту не виконуються. Для відкату є копія 1.1.0 у `backups/cinema-upgrade-20261022/`.
